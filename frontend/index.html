Risk ≠ Confidence

Risk score: how severe/likely the model estimates the hazard to be.

Confidence: how strongly the available evidence supports that assessment.

Example: high predicted risk + weak evidence should trigger verification, not automatic escalation.

Validation plan

  1. Back-test historical events
  2. Calibrate thresholds by terrain/district
  3. Measure precision, recall and false-alert rate
  4. Run field pilot with disaster-management experts

Important demo note

This prototype demonstrates the end-to-end software workflow. It must not be represented as a live government warning service or as a clinically/operationally validated prediction model.
